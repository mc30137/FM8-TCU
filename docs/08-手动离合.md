# 阶段 8：手动离合换挡

> 适用场景：游戏里把变速箱设成 **「手动带离合」（Manual with Clutch）**。
> 这种设定下，只按换挡键不会进挡——必须先踩离合，游戏才认这次换挡。

## 为什么需要它

普通模式下，程序只是"按一下 num9 / num7"。但在手动带离合的车上，
这一下会被游戏当成 **无离合硬挂**：要么不进挡，要么掉转速、伤同步。
玩家自己开的时候是「踩离合 → 拨挡 → 松离合」，程序也得照做。

## 时序

按键顺序参考 [`forza-horizon-6-tgt2-shifter`](https://github.com/Yuandiaodiaodiao/forza-horizon-6-tgt2-shifter)
公开记录的 `keyboard_clutch` 行为（本项目为独立实现，未复制其代码）：

```
挡位键  ──按下──────────────────────────────抬起──
离合键        ──按下────40ms────抬起──
         10ms                        10ms
```

也就是：

| 步骤 | 动作 | 时长 |
|---|---|---|
| 1 | 挡位键按下 | — |
| 2 | 等 | 10ms |
| 3 | 离合键按下 | — |
| 4 | 等（离合保持） | 40ms |
| 5 | 离合键抬起 | — |
| 6 | 等 | 10ms |
| 7 | 挡位键抬起 | — |

三个要点：

- **挡位键先按、后松。** 离合接合的那一瞬间，挡位键必须还按着，
  否则游戏看到的仍然是"没挂上"。
- **抬起顺序和按下相反。** 先松离合再松挡位，等于"踩着挡位接合"；
  反过来就是无离合松挡，车会顿一下。
- **总时长不变（默认 60ms）。** 前段 + 离合 + 后段 = `--hold`，
  所以换挡延迟和普通模式一样，不需要重新标定。

`--clutch-hold` 可以改离合保持的时长（默认 40ms）。如果游戏里经常
"挂不上"，先试着加到 60ms；如果换挡偏慢，可以减到 30ms 试试。

## 怎么开

### 图形界面

底部多了一个勾选框 **「手动离合（shift）」**：

- 勾上 = 换挡时踩离合；取消 = 回到普通换挡。
- 勾选状态记在 `ui.json`，下次启动自动恢复。
- 如果启动时没给离合键（`--clutch-key none` 之类），勾选框是灰的。

### 命令行

```bat
python -m fm8_tcu.app --clutch --clutch-key shift --clutch-hold 40
```

面板上会显示「手动离合」，**F10** 随时开关。

### 参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `--clutch` | 关 | 启动即开启手动离合 |
| `--clutch-key` | `shift` | 离合键名，必须和游戏里的绑定一致 |
| `--clutch-hold` | `40` | 离合按住的毫秒数 |

可用的键名见 `outputs.py` 的 `SCANCODES`（`shift` / `ctrl` / `space` /
字母 / 小键盘）。

## 前提与限制

1. **游戏里必须设成「手动带离合」**。设成「手动」的话，多踩一脚离合
   没有副作用，但也没意义；设成「自动」时程序本来就不该开这个。
2. **离合键要和游戏绑定一致**。程序发的是键盘扫描码，游戏里绑的是
   哪个键，这里就得写哪个。默认 `shift` 是 Forza 的默认离合键。
3. **进挡时间可能变长**。离合多按的 40ms 是在原有 60ms 之内挤出来的，
   所以命令发出到挡位变化的延迟基本不变；但如果游戏对"离合完全踩下"
   有额外要求，实测延迟可能多 20–40ms。`decisions.csv` 里的 `延迟ms`
   会如实记录。
4. **失败仍然是失败**。离合按错键、游戏没认，结果就是 `pending` 超时，
   统计里会出现"超时"。这一层没有做"重试"——连按两次挡位键在手动
   带离合的车上会变成两次挂挡。

## 测试

`tests/test_outputs.py` 用注入的 send/sleep 记录器验证时序，不碰真键盘：

- 普通模式：只动挡位键，按住 60ms
- 离合模式：按下/抬起顺序、10/40/10 的三段时长、总时长不变
- 离合键发不出去时，挡位键必须被抬起来（不能留在按下状态）
- `release_all()` 连离合一起抬
- `set_clutch()` 开关真的影响发键
